- 当前主线应固定 Qwen3-32B，进入正式 sampled strict paired 或继续做少量有边界的 WTQ 通用修复。

## 11. Recommended Experiment Plan

full 数据规模：

| dataset | full rows |
|---|---:|
| WTQ | 4,344 |
| TabFact | 12,779 |
| CRT | 728 |
| Total | 18,301 |

不建议把 full 作为日常迭代目标。按当前实测，Qwen3-32B myAgent frozen150 约 2.4 小时，MACT one-by-one 更慢；full 三数据集每轮会消耗数天，且会阻塞模型筛选。

推荐正式流程：

| stage | scope | run | stop rule |
|---|---|---|---|
| Smoke | 5-20/数据集 | myAgent only | failed/missing、context error 或 token 异常就停 |
| Gate-50 | frozen first50/数据集 | myAgent only；必要时与已有 MACT/Qwen3 对齐 | overall 明显低于 MACT 或当前 Qwen3-32B 就不扩大 |
| Frozen150 | frozen150/数据集 | 只给 1-2 个候选 strict paired | 要求 overall >= MACT、至少 2 个数据集 >= MACT、token <= 0.75 MACT、failed <= 2% |
| Formal sample | 200 或 300/数据集 | 最终模型 strict paired | 写专家/专利主表 |
| Ablation | 50 或 100/数据集 | selected toggles only | 解释机制，不追求每个消融 full |
| Full dataset | optional background | final model only | 不作为常规模型筛选或调参动作 |

建议专家材料主实验：

1. 固定 `Qwen3-32B`、当前 `selective-risk-collaboration` 提交、dataset split 和 evaluator。
2. 以 frozen150 shortcutfix 作为阶段性已通过证据。
3. 下一步跑 formal sample `200/数据集` 或 `300/数据集` 的 strict paired。若服务器时间紧，优先 `200/数据集`。
4. 消融只跑 `50/数据集` 或 `100/数据集`：
   - `legacy collaboration`
   - `no strong verification`
   - `no deterministic shortcuts`
   - `max-replan 0/1/2`
5. full 数据集只在最终版本空闲时后台跑一次，用作附录，不作为每轮实验要求。

可写入专家材料的稳妥表述：

```text
在同一 Gate-50 split 上，小模型 Qwen2.5-3B 和中型量化模型 Qwen3-14B-AWQ、Qwen2.5-14B-AWQ
均可稳定运行，但准确率不足；当前 Qwen3-32B 是唯一通过 strict paired stage gate 的本地候选模型。
因此正式实验优先采用 Qwen3-32B，并通过 200/数据集或 300/数据集 sampled strict paired 控制时间成本。
```
