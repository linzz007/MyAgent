选择 Qwen3-14B-AWQ 的原因：

- 与当前主模型 Qwen3-32B 同系列，能检验 14B 量化模型是否足够承载 myAgent 策略。
- AWQ 4-bit 可单 GPU 运行，适合作为中型候选。

下载命令：

```bash
source /home/ubuntu/miniconda3/etc/profile.d/conda.sh
conda activate lzz-agent
mkdir -p /home/ubuntu/models/Qwen3-14B-AWQ
HF_HUB_DISABLE_XET=1 hf download Qwen/Qwen3-14B-AWQ \
  --local-dir /home/ubuntu/models/Qwen3-14B-AWQ
```

重要运行发现：

- 默认 `hf download` 使用 `hf_xet` 时卡住，进程停在 `snapshot_download` thread wait，`.incomplete` 文件不再增长。
- 设置 `HF_HUB_DISABLE_XET=1` 后下载恢复真实增长并完成。
- 下载总耗时约 `1h01m49s`。
