## 📊 数据集格式对比

| 数据集 | 格式 | 表格存储 | 问题数量 | 特点 |
|--------|------|----------|----------|------|
| WikiTableQuestions | TSV | CSV文件（外部） | 1问题/样本 | 简单，表格独立存储 |
| HiTab | JSONL | list-of-lists（嵌入） | 1问题/样本 | 表格嵌入，支持复杂结构 |
| TAT-QA | JSON | list-of-lists（嵌入） | 多问题/表格 | 一个表格多个问题 |

## 🔍 数据格式详情

### WikiTableQuestions (TSV)
```tsv
id	question	table_path	answer
test-wtq-1	what was the last year...	test_csv/590.csv	2004
```

**字段说明**:
- `id`: 样本ID
- `question`: 问题文本（也支持`utterance`）
- `table_path`: CSV表格相对路径（也支持`context`）
- `answer`: 答案（也支持`targetValue`）

### HiTab (JSONL)
```json
{
  "id": "test-hitab-1",
  "question": "...",
  "table_text": [["", "col1", "col2"], ["row1", "val1", "val2"]],
  "answer": [154983.0]
}
```

**字段说明**:
- `id`: 样本ID
- `question`: 问题文本
- `table_text`: 表格数据（list-of-lists，二维数组）
- `answer`: 答案（数组格式）

### TAT-QA (JSON)
```json
[
  {
    "table": {
      "uid": "test-table-1",
      "table": [["", "col1"], ["row1", "val1"]]
    },
    "questions": [
      {
        "question": "...",
        "answer": ["$1,496.5"],
        "answer_from": "table-text"
      }
    ]
  }
]
```

**字段说明**:
- `table`: 表格对象，包含`uid`和`table`（list-of-lists）
- `questions`: 问题数组，每个问题包含`question`、`answer`等

## 🛠️ 代码处理逻辑

### WikiTableQuestions
1. 读取TSV文件，解析表头和样本
2. 从`table_path`读取CSV文件
3. 使用`pd.read_csv()`加载DataFrame
4. 调用`_build_table_schema()`构建schema

### HiTab
1. 逐行读取JSONL文件
2. 从`table_text`字段提取list-of-lists
3. 调用`build_df_from_table()`将list-of-lists转换为DataFrame
4. 调用`_build_table_schema()`构建schema

### TAT-QA
1. 读取JSON文件（支持数组或`{data: [...]}`格式）
2. 遍历每个表格样本
3. 从`table.table`字段提取list-of-lists
4. 调用`build_df_from_table()`将list-of-lists转换为DataFrame
5. 对每个问题单独处理

## 📝 测试脚本选项

### validate_dataset_formats.py
- 不需要LLM
- 只验证数据格式和DataFrame构建
- 快速验证数据文件是否正确

### test_three_datasets.py
- 需要LLM（DeepSeek或GPT）
- 完整测试Router路由功能
- 输出路由结果、分数等详细信息

**选项**:
- `--plan_model_name`: LLM模型名称
- `--wtq_path`: WikiTableQuestions文件路径
- `--hitab_path`: HiTab文件路径
- `--tatqa_path`: TAT-QA文件路径
- `--skip_wtq`: 跳过WikiTableQuestions
- `--skip_hitab`: 跳过HiTab
- `--skip_tatqa`: 跳过TAT-QA

## 🐛 常见问题

### Q: CSV文件找不到？
A: 确保`test_csv/`目录存在，且CSV文件路径正确。

### Q: DataFrame构建失败？
A: 检查`table_text`或`table.table`是否为有效的list-of-lists格式。

### Q: LLM调用失败？
A: 检查环境变量`DASHSCOPE_API_KEY`是否设置，或使用`--skip_*`选项跳过需要LLM的测试。
