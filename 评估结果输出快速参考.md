# 评估结果输出快速参考

## 🎯 一键运行（TAT-QA示例）

```bash
cd code

# 1. 生成预测
conda run -n lzz-agent python run_all_datasets.py

# 2. 转换格式
conda run -n lzz-agent python convert_for_evaluation.py \
    --pred_file tatqa_predictions.jsonl \
    --output_file tatqa_predictions_for_eval.json \
    --dataset tat \
    --gold_file ../dataset/test_samples_tatqa.json

# 3. 运行评估并保存结果
conda run -n lzz-agent python run_evaluation_with_output.py \
    --dataset tat \
    --pred_file tatqa_predictions_for_eval.json \
    --gold_file ../dataset/test_samples_tatqa.json \
    --output_file tatqa_evaluation_results.json

# 4. 查看结果
cat tatqa_evaluation_results.json | python -m json.tool | head -30
```

## 📊 输出文件结构

```
tatqa_evaluation_results.json
├── overall_metrics          # 总体指标
│   ├── exact_match_accuracy
│   ├── f1_score
│   └── scale_score
├── detail_metrics           # 详细指标（按维度统计）
├── per_sample_results       # 每个样本的详细结果
│   ├── uid
│   ├── question
│   ├── gold_answer / pred_answer
│   ├── exact_match
│   └── f1_score
└── summary                  # 摘要统计
```

## 🔍 常用查看命令

```bash
# 查看总体指标
cat tatqa_evaluation_results.json | python -c "import json,sys; d=json.load(sys.stdin); print(f\"EM: {d['overall_metrics']['exact_match_accuracy']:.2f}%, F1: {d['overall_metrics']['f1_score']:.2f}%\")"

# 查看错误样本
cat tatqa_evaluation_results.json | python -c "import json,sys; d=json.load(sys.stdin); [print(f\"{s['uid']}: {s['question']}\") for s in d['per_sample_results'] if not s['exact_match']]"
```
