# 如何输出官方评估器评估之后的答案

## 📋 概述

使用 `run_evaluation_with_output.py` 脚本可以运行官方评估器，并将详细的评估结果保存到JSON文件中。

## 🚀 使用方法

### 1. TAT-QA数据集评估

```bash
cd code

# 基本用法（自动生成输出文件名）
conda run -n lzz-agent python run_evaluation_with_output.py \
    --dataset tat \
    --pred_file tatqa_predictions_for_eval.json \
    --gold_file ../dataset/test_samples_tatqa.json

# 指定输出文件
conda run -n lzz-agent python run_evaluation_with_output.py \
    --dataset tat \
    --pred_file tatqa_predictions_for_eval.json \
    --gold_file ../dataset/test_samples_tatqa.json \
    --output_file my_evaluation_results.json
```

### 2. WTQ数据集评估

```bash
cd code

conda run -n lzz-agent python run_evaluation_with_output.py \
    --dataset wtq \
    --pred_file wtq_predictions.tsv \
    --gold_file ../dataset/test_samples_wtq.tsv \
    --output_file wtq_evaluation_results.json
```

## 📊 输出结果格式

评估结果会保存为JSON文件，包含以下部分：

### 1. 总体指标 (overall_metrics)

```json
{
  "overall_metrics": {
    "exact_match_accuracy": 66.67,    // EM准确率（%）
    "f1_score": 66.67,                 // F1分数（%）
    "scale_score": 100.0,              // Scale匹配率（%）
    "operation_score": null             // 操作匹配率（如果有）
  }
}
```

### 2. 详细指标 (detail_metrics)

包含按不同维度（如answer_from, answer_type）统计的详细指标。

### 3. 每个样本的详细结果 (per_sample_results)

```json
{
  "per_sample_results": [
    {
      "uid": "q1",                      // 问题ID
      "question": "What is...",         // 问题文本
      "gold_answer": ["$1,496.5"],     // 标准答案
      "pred_answer": ["$1,496.5"],     // 预测答案
      "gold_scale": "million",         // 标准scale
      "pred_scale": "million",         // 预测scale
      "exact_match": true,             // 是否完全匹配
      "f1_score": 1.0,                 // F1分数
      "scale_match": true              // Scale是否匹配
    }
  ]
}
```

### 4. 摘要统计 (summary)

```json
{
  "summary": {
    "total_samples": 3,                // 总样本数
    "exact_match_count": 2,            // 完全匹配数量
    "scale_match_count": 3,            // Scale匹配数量
    "average_f1": 0.67                 // 平均F1分数
  }
}
```

## 📝 完整示例

### 步骤1：生成预测结果

```bash
cd code
conda run -n lzz-agent python run_all_datasets.py
```

### 步骤2：转换为评估器格式

```bash
# TAT-QA
conda run -n lzz-agent python convert_for_evaluation.py \
    --pred_file tatqa_predictions.jsonl \
    --output_file tatqa_predictions_for_eval.json \
    --dataset tat \
    --gold_file ../dataset/test_samples_tatqa.json

# WTQ
conda run -n lzz-agent python convert_for_evaluation.py \
    --pred_file wtq_predictions.jsonl \
    --output_file wtq_predictions.tsv \
    --dataset wtq
```

### 步骤3：运行评估并保存结果

```bash
# TAT-QA
conda run -n lzz-agent python run_evaluation_with_output.py \
    --dataset tat \
    --pred_file tatqa_predictions_for_eval.json \
    --gold_file ../dataset/test_samples_tatqa.json \
    --output_file tatqa_evaluation_results.json

# WTQ
conda run -n lzz-agent python run_evaluation_with_output.py \
    --dataset wtq \
    --pred_file wtq_predictions.tsv \
    --gold_file ../dataset/test_samples_wtq.tsv \
    --output_file wtq_evaluation_results.json
```

### 步骤4：查看结果

```bash
# 查看JSON文件
cat tatqa_evaluation_results.json | python -m json.tool

# 或者使用jq（如果已安装）
cat tatqa_evaluation_results.json | jq '.overall_metrics'
cat tatqa_evaluation_results.json | jq '.per_sample_results[] | select(.exact_match == false)'
```

## 🔍 结果分析示例

### 查看总体指标

```python
import json

with open('tatqa_evaluation_results.json', 'r', encoding='utf-8') as f:
    results = json.load(f)

print("总体指标:")
print(f"  EM准确率: {results['overall_metrics']['exact_match_accuracy']:.2f}%")
print(f"  F1分数: {results['overall_metrics']['f1_score']:.2f}%")
print(f"  Scale匹配率: {results['overall_metrics']['scale_score']:.2f}%")
```

### 查看错误样本

```python
import json

with open('tatqa_evaluation_results.json', 'r', encoding='utf-8') as f:
    results = json.load(f)

print("错误样本:")
for sample in results['per_sample_results']:
    if not sample['exact_match']:
        print(f"  {sample['uid']}: {sample['question']}")
        print(f"    预测: {sample['pred_answer']}")
        print(f"    标准: {sample['gold_answer']}")
```

### 统计不同问题类型的准确率

```python
import json
from collections import defaultdict

with open('tatqa_evaluation_results.json', 'r', encoding='utf-8') as f:
    results = json.load(f)

# 按问题类型统计（可以根据需要修改分类逻辑）
type_stats = defaultdict(lambda: {'correct': 0, 'total': 0})

for sample in results['per_sample_results']:
    # 简单的分类逻辑（可以根据实际情况修改）
    q_type = 'other'
    if 'what' in sample['question'].lower():
        q_type = 'what'
    elif 'how' in sample['question'].lower():
        q_type = 'how'
    
    type_stats[q_type]['total'] += 1
    if sample['exact_match']:
        type_stats[q_type]['correct'] += 1

print("按问题类型统计:")
for q_type, stats in type_stats.items():
    acc = stats['correct'] / stats['total'] * 100 if stats['total'] > 0 else 0
    print(f"  {q_type}: {stats['correct']}/{stats['total']} = {acc:.2f}%")
```

## 📈 与MACT对比

评估结果文件可以直接用于与MACT论文的结果对比：

1. **总体指标对比**：
   - 比较 `overall_metrics` 中的 `exact_match_accuracy` 和 `f1_score`
   - MACT论文中报告的指标应该与这些指标对应

2. **详细分析**：
   - 使用 `per_sample_results` 分析哪些类型的问题表现好/差
   - 可以按问题类型、答案类型等维度进行细分分析

3. **错误分析**：
   - 筛选 `exact_match == false` 的样本
   - 分析错误原因（答案错误、scale错误、格式问题等）

## 💡 提示

1. **自动生成输出文件名**：如果不指定 `--output_file`，脚本会自动生成文件名（基于预测文件名）

2. **控制台输出**：脚本会在控制台打印评估结果摘要，同时保存详细结果到JSON文件

3. **错误处理**：如果评估过程中出错，脚本会打印错误信息，但不会保存不完整的结果

4. **文件格式**：确保预测文件格式正确（TAT-QA需要JSON格式，WTQ需要TSV格式）
